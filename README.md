
# Little Lemon - Table Booking Website

## Project Description
A React application demonstrating a table booking form for the Little Lemon restaurant.

## Features
- Select a booking date
- Choose a booking time
- Enter the number of guests
- Select an occasion
- Validate booking details
- Display feedback after form submission
- Responsive design for desktop and mobile

## Technologies Used
- React
- JavaScript
- HTML5
- CSS3
- Jest
- React Testing Library

## Requirements
- Node.js and npm
- Git

## Installation
Clone the repository and open the project folder in the terminal.

Install dependencies:

    npm install

## Run the Application

    npm start

Open http://localhost:3000 in your browser.

## Run Unit Tests

    npm test -- --watchAll=false

## Project Structure
- public/ - Static assets
- src/App.js - Booking form and validation
- src/App.css - Styling and responsive layout
- src/App.test.js - Unit tests
- package.json - Project configuration
- README.md - Project documentation

## Limitations
This version demonstrates form validation and confirmation feedback.
It does not create a real restaurant reservation or connect to a booking API.
